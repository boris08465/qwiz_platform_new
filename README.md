# Qwiz Platform

Веб-приложение для создания и прохождения тестов: Flask + Oracle.
Запуск из Python, без Docker и отдельного установщика. Подключение уже настроено в `db.py`:

| Параметр | Значение |
| --- | --- |
| Сервер | `10.22.10.40` |
| Порт | `1521` |
| SID | `ORCL` |
| Пользователь | `KE2302_07` |
| Пароль | `KE2302_07` |

Нужны Python 3.10+ и доступ к сети сервера Oracle (при необходимости через VPN).
Устанавливать Oracle на свой компьютер не нужно. Приложение и `manage.py` используют
одни настройки из `db.py`; отдельно вводить их при обычном запуске не требуется.

## Запуск

Откройте терминал в папке проекта. Windows / PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py check-db
.\.venv\Scripts\python.exe -m flask --app app run --host 127.0.0.1 --port 5063
```

macOS / Linux:

```sh
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python manage.py check-db
./.venv/bin/python -m flask --app app run --host 127.0.0.1 --port 5063
```

Если проверка базы завершилась ошибкой, сначала устраните её по инструкции ниже.
После запуска откройте **http://127.0.0.1:5063** и оставьте терминал открытым.
Для повторного запуска нужна только последняя команда; остановка — Ctrl+C.

## Инструкции

- [Подготовка базы, запуск и работа с приложением](docs/START_HERE_RU.md).
- [Чек-лист тестирования](docs/TEST_CHECKLIST_RU.md).

**Схема при запуске сайта не создаётся автоматически.** Если Qwiz ещё не установлен,
ответственный за базу один раз выполняет `sql/00_install_all.sql` в пустой схеме
`KE2302_07`. Для существующей версии используется `sql/10_upgrade_workflow.sql`.
Подробности — в инструкции. Скрипты `08_seed_test_data.sql` и `99_drop_all.sql`
удаляют данные: не выполняйте их в общей схеме ради проверки запуска.

Первый зарегистрированный пользователь пустой базы становится администратором.
Вход на сайт — по числовому UID и паролю, созданным при регистрации, а не по реквизитам Oracle.
Все проверяющие с указанным подключением работают с одной общей базой.

## Для разработчика

Проверки без подключения к Oracle (используйте Python своего окружения):

```sh
python -m unittest discover -s tests -v
python scripts/build_sql.py --check
```

Для полной проверки нужна отдельная одноразовая схема `QWIZ_TEST`; порядок описан
в чек-листе. Не направляйте удаляющие данные тесты в `KE2302_07`.
Переменные `DB_USER`, `DB_PASSWORD`, `DB_DSN` могут переопределять значения из `db.py`
для отдельного окружения; обычному пользователю они не нужны.

SQL-исходники: `01`–`07` и `09`. После их изменения выполните `python scripts/build_sql.py`,
чтобы обновить объединённые скрипты `00` и `10`.
